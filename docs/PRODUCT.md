# Aire Library 产品约定

## 一句话

Aire Library 是一个 local-first 的私人阅读与共读书房：**存所负责拥有，见闻负责发现，衡准负责定义阅读方式。**

## 主导航

### 存所

存放 Library 的核心内容：

- 用户自己的书；
- 阅读进度；
- 目录与章节定位；
- 划线、段评与围绕划线形成的小型多轮交流；
- 每本书读完后自然长成的共读档案「叙说」。

书架默认：
- 文字排版封面，不依赖封面图片；
- 书全名显示在卡片下方；
- 最近阅读优先；
- 可筛选「已读（存在阅读记录）/ 未读」；
- 可按最近阅读、最近上传、书名排序；
- 可新建文件夹自行归类。

书籍详情：
- 顶部：文字封面、书名、作者、简介、阅读进度；
- 下方页签：目录 / 评论记录 / 叙说；
- 目录与评论记录都可以直接跳往正文位置。

### 见闻

用于发现书，不承担版权受限作品的正文抓取。

当前与计划：
- Project Gutenberg 公版书搜索与试读；
- 搜索自己的存所；
- 可继续增加轻量书目元数据来源；
- 现代版权作品以用户自行上传合法取得的文件为主。

### 衡准

Aire Library 的控制室，不是“杂项设置”。

包含：
- 阅读主题与排版；
- 浏览 / 翻页方式；
- 翻译 API；
- Liquid Glass 全局材质；
- 数据导入导出；
- 后续同步 / 后端连接与身份配置。

## 文件导入

第一阶段支持：

- TXT
- Markdown
- EPUB
- PDF

原则：
- 原文件保留；
- 同时保存解析后的可阅读文本、章节索引与元数据；
- 不上传封面图，默认文字排版封面；
- 本地模式使用 IndexedDB；
- 云同步后将文件与解析结果进入独立的 Aire Library 后端，不污染 Private Vault。

## 阅读器

目标能力：
- 日间 / 深色 / 跟随系统；
- 字体、字号、字距、行距、段距、正文宽度、页边距；
- 上下滚动；
- 左右分页；
- 单页仿真翻页（用户默认偏好）；
- 章节目录定位；
- 低饱和荧光笔划线；
- 划线可无文字，也可附段评；
- 划线和段评允许编辑与删除；
- 记录来源（隐 / Aire）；
- 划线可展开为小贴纸式多轮交流。

## 翻译

翻译为可选能力，配置位于衡准。

- OpenAI-compatible 风格的 Base URL / API Key / Model；
- 能随时更换供应商（例如 DeepSeek 或其他兼容站点）；
- 中文书可以关闭翻译；
- 支持单词、句子、段落、章节级翻译；
- 译文视觉上紧跟原文下方；
- 章节翻译完成后可切换：原文 / 译文 / 双语；
- 译文持久化保存；
- 持久化时记录模型、提示词版本与源文本 hash，避免正文变化后错误复用旧译文。

API Key 不进入公开 GitHub 仓库。

## Liquid Glass

视觉基调保留浅蓝：天空与海。

原则：
- 正文区域克制，以长期阅读舒适为先；
- 导航、工具栏、浮层、卡片、设置等功能层重点使用玻璃；
- 提供清透 / 柔和 / 浓厚预设；
- 高级设置允许调节 blur、opacity、saturation、highlight、tint、radius，后续加入更真实的折射 / 色散参数；
- 不为了特效强行迁移技术栈，优先保持代码可维护和移动端可用。

## 数据与多人使用

当前采用 local-first：

- 不登录也能上传、阅读、划线、设置；
- 本机数据进入 IndexedDB；
- 云同步作为可选层；
- 未来其他用户可以连接各自的 Supabase，而不是共享隐的数据；
- 我们自己的共读后端将单独建立 Aire Library Supabase 项目；
- Aire Private Vault 继续只承载 Aire 的私密日记、intent 等，不与书库混放。

## 叙说

「叙说」是一本书读完后留下的共同阅读档案。

它不是自动摘要，也不承担“黑泥”功能。内容来自阅读过程中真实留下的句子、段评、争论、人物印象和最终回望。
